# Dashboard Profissional

Dashboard desenvolvido em Python com Streamlit para apresentação profissional e análise de dados.

## Sobre o projeto

O projeto apresenta informações sobre minha formação, qualificações e habilidades, além de uma análise do perfil de estagiários no mercado de dados e tecnologia no Brasil.

## Base de Dados

Foi utilizada a base pública **State of Data Brazil 2025-2026**, disponibilizada pela Data Hackers no Kaggle.

A análise considera os participantes que informaram atuar como estagiários.

## Análises realizadas

- Faixa salarial
- Modelo de trabalho
- Área de formação
- Cargos
- Experiência em TI

## Tecnologias utilizadas

- Python
- Streamlit
- Pandas
- Plotly
