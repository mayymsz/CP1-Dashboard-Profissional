# Dashboard Profissional com Análise de Dados

Dashboard profissional desenvolvido em **Python com Streamlit** para a disciplina de **Data Science and Statistical Computing** da FIAP.

O projeto reúne informações sobre meu perfil profissional e uma análise de dados sobre estagiários no mercado brasileiro de Dados e Tecnologia.

## Acesso ao Dashboard

**Dashboard publicado:**  
https://mayene-dashboard-profissional.streamlit.app/

## Sobre o Projeto

O dashboard está dividido em quatro seções principais:

### Quem sou eu
Apresentação profissional com informações sobre minha formação, área de interesse e foco atual em desenvolvimento de software.

### Minhas Qualificações
Informações sobre formação acadêmica, experiências e projetos desenvolvidos durante a graduação.

### Skills
Competências organizadas entre:

- Linguagens
- Ferramentas
- Conhecimentos técnicos
- Soft Skills

### Análise de Dados
Análise do perfil de estagiários no mercado brasileiro de Dados e Tecnologia.

Foram analisadas informações relacionadas a:

- Faixa salarial
- Modelo de trabalho
- Linguagens utilizadas
- Área de formação
- Experiência em TI

O dashboard também possui filtros e gráficos interativos que permitem explorar e comparar os dados apresentados.

## Base de Dados

A análise utiliza dados da pesquisa **State of Data Brazil 2025-2026**, considerando os participantes que informaram estar atuando como estagiários.

**Fonte:** [State of Data Brazil 2025-2026](https://www.kaggle.com/datasets/datahackers/state-of-data-brazil-2025-2026)

## Tecnologias Utilizadas

- Python
- Streamlit
- Pandas
- Plotly
- HTML
- CSS

## Como Executar o Projeto

Clone o repositório:

    git clone https://github.com/mayymsz/CP1-Dashboard-Profissional.git

Entre na pasta:

    cd CP1-Dashboard-Profissional

Instale as dependências:

    pip install -r requirements.txt

Execute o dashboard:

    streamlit run app.py

Depois, acesse o endereço local exibido pelo Streamlit no terminal.
